# Bunny v3.1 plan

Status: not started. Collected during the v3.0 redesign (November 2026) from Rahul's requests
and from gaps found while testing. Nothing here is in v3.0.

Each item says what was asked, what was agreed, and what is still open.

## 1. Remote hand-off over SSH

**Asked:** run a hand-off on another machine. Same note, same hand-off card; choose a server from
a list instead of running locally.

**Agreed**
- Off by default, behind one switch in Settings. When off, nothing about servers shows anywhere.
- A **Servers** page in Settings (shown only when the switch is on):
  - Add a server ahead of time: name, address, user, port, default remote folder.
  - Key: the user picks a private key *file*. Bunny stores the path only. Never key contents,
    never passwords. Passphrases are left to the macOS key agent.
  - Import hosts from `~/.ssh/config`.
  - "Test connection" per server: checks sign-in and that `claude` / `codex` is installed there.
- The hand-off options card gets a **Run on** row: This Mac, or one of the servers.
- Key-based sign-in only. A host that asks for a password is refused with a clear message.
- How it works: the agent runner's pipe goes through `ssh` instead of a local process. Opening the
  session opens a terminal that runs `ssh -t <host>` and resumes it there.

**Open**
- Attachments live on the Mac, not the server. Recommended: copy attached files up to about 20 MB
  to a temporary folder on the server before the run, and skip folders with a note saying so.
- Folder on the server. Recommended: a default per server, plus a text field in the card to change
  it for one run, with recent remote paths remembered. There is no Finder picker for a server.

**Limits to state in the UI**
- The agent must already be installed and signed in on the server.
- Bunny tools do not work for remote runs: the server cannot reach the listener on the Mac.
- Needs testing against a real server before release.

## 2. Background image

**Asked:** let people put a wallpaper or theme image behind their notes, subtle, not pasted on top.

**Agreed**
- A "Background image" row on Settings → Appearance (already shown there, disabled, tagged v3.1).
- The image is heavily blurred and dimmed, with a strength slider.
- Blur once and cache the result, so there is no ongoing GPU cost.
- Text contrast must hold over any image: keep a tinted plate between image and text.

## 3. Glass surface option

**Asked:** a Glass / Solid choice, following the Mac's own transparency setting.

**State:** v3.0 ships Solid only. Glass was removed after two problems:
- It left a ghost of the window on screen for a moment after closing.
- Applied to the window's content, it silently blocked drag and drop.

**Agreed:** bring back a Glass / Solid switch only if both are solved. Glass must be drawn as a
background, never on the content. When the Mac has Reduce Transparency on, Bunny is always solid.

## 4. "Custom command…" for opening sessions

**Asked:** more freedom over where a session opens.

**In v3.0:** Terminal, VS Code, the agent's own app, and "Other App…" (apps that cannot open a
session are greyed out).

**For v3.1:** a "Custom command…" choice for anything unusual. The user types the command Bunny
runs, with placeholders for the folder and the resume command.

## 5. Folder memory for new notes

A note created right after a hand-off starts with that same folder selected. Deferred because the
"recent folders" list in the card already makes it one click, and it needs real use to tune.

## 6. Optional hover preview

v3.0 opens a note on click only. If people ask for it, add an opt-in hover preview with a long
delay (Maccy's default is 1.5 s), off by default.

## 7. Smaller items found during testing

Agents
- Messages typed while an agent is mid-step are dropped if that step fails or is stopped. Keep them
  queued and offer to resend.
- Undo does not restart an agent that Delete stopped.
- "Hand off again" uses the default agent, not the agent of the old session. Decide which is right.
- The Codex app deep link cannot report "opened, but not the right conversation". Find a check.
- Cursor and other VS Code forks open Claude sessions through a link that is only documented for
  VS Code. Verify per app, or drop the ones that fail.

Notes and list
- A search match inside details shows only the title. Show a short snippet.
- Switching between the note and the agent keeps the text but not the cursor or scroll position.
- Export writes subtasks as checklist lines only. Include a subtask's own details and attachments.

Settings
- Shortening "Empty Trash" deletes older trashed notes at once with no confirmation. Add one.
- The timer picker and the Welcome window still use the default light palette in places. Bring
  them onto the warm palette.
- Typing in Settings with nothing focused makes macOS beep.

Release
- "Check for updates" cannot see pre-releases.
- The app is not notarized. Revisit if a Developer ID becomes available.

## 8. Considered and not scheduled

- Accounts, cloud storage and sync across devices. Raised at the start and set aside; Bunny is
  local-only by design for now.
- Tags, folders or projects for notes.
- Rich text or Markdown rendering in notes.
- A built-in screenshot tool.
- Readable names for attachment folders on disk. Kept as note IDs on purpose (renames stay safe);
  Export is the readable view.
