Bunny 3.0.0 is a redesign. Bunny is a notes list first again: one window under the menu bar icon, a note side that opens next to the list, a Trash, and a full Settings window. Handing a note to Claude Code or Codex is still there, but it is optional, off by default, and asks before it runs commands. The window and interaction bugs of v2 are fixed, and delete and the keyboard shortcuts from v1.0 are back.

## New

**Window and list**
- One window under the menu bar icon. A click on a note opens it beside the list; the window closes when you click elsewhere, unless the note is pinned.
- Selection with click, shift-click and ⌘-click, with actions for the selection and a context menu.
- Keyboard: ⌘N, ⌘F, ↑/↓, Return, Space, ⌫, ⌥↑/⌥↓, ⌘A, ⌘C, ⌘Z, Esc.
- Search, and Undo for completing and trashing.
- A Completed group at the bottom of the list.
- An optional global shortcut that opens Bunny ready for a new note.

**Notes**
- Details with clickable links.
- Attachments (files, folders, images) added by paste, drag or the + button.
- A new note typed on several lines becomes a title plus details.
- Copy as Prompt: title, details, subtasks and attachment paths as plain text.
- Starting a timer shows the note in the menu bar; a notification fires when it ends.

**Trash**
- Deleting moves a note to Trash. Restore or Delete Forever from the Trash view.
- Trash empties itself after 7, 30 (default) or 90 days, or never.

**Settings**
- A window with search and six pages: General, Appearance, Notes, Agents, Data, About.
- Launch at login, global shortcut, theme (System, Light, Dark).
- Data: sizes on disk, Export all notes (Markdown plus attachments), Empty Trash, Reset settings, Erase all data.
- About: Check for updates. It looks up the latest GitHub release and links to it; nothing installs itself.
- A two-page Welcome guide on first launch.

**Agents**
- An on/off switch per agent. With both off, no agent controls show and no agent code runs.
- Hand off starts at once. Its options card sets folder, agent, model and effort for that note.
- The agent's state shows in the note: working, needs input, failed, finished. Questions are answered in the note.
- A message field and a short thread in the note continue the same session.
- The note side shows either the note or the agent in full; the other folds to a line.
- A yellow dot on the menu bar icon and a notification when an agent needs input.
- "Open sessions in" per agent: Terminal, VS Code, the Claude or Codex app, or another app.

## Changed from v2

- There is no Archive. Notes archived by older versions move to Trash at the first launch.
- Completed notes move to Trash after 24 hours by default (7 days or never in Settings → Notes).
- On a fresh install the agents and Bunny tools are off. Agents ask before running commands unless you choose "Autonomous".
- Agents never work in your home folder. The default is Bunny's own empty folder.
- The window surface is solid. The glass surface is gone for now.

## Upgrading

- Requires macOS 26 or later.
- Notes from v1.0 and v2.0.0 carry over. Replace the app in Applications; nothing else is needed.
- Before v3 opens the database for the first time it saves a copy to `~/Library/Application Support/Bunny/Backups/pre-v3/`.
- If you used agents in v2, the agents Bunny had found stay switched on.

## Install

1. Download `Bunny.dmg` below, open it and drag Bunny to Applications.
2. Open Bunny once. macOS blocks it, because the app is not notarized.
3. Go to System Settings → Privacy & Security, scroll down, and click **Open Anyway**. Open Bunny again and confirm.

Or run `xattr -dr com.apple.quarantine /Applications/Bunny.app` in place of steps 2 and 3.

## Known limits

- Not notarized, and signed ad hoc: we have no paid Apple developer account. Right-click → Open does not get past this on current macOS; use the steps above.
- Opening a session in the Claude or Codex app, or in a third-party terminal, is best-effort. Terminal is the reliable choice.
- A message sent while an agent is working is delivered when that step ends. If the step fails or is stopped, the queued message is dropped.
- Background image (Settings → Appearance) is a placeholder for v3.1.
- No automatic updates. Use Settings → About → Check for updates.
- UI checks are done with rendered snapshots, which cannot cover hover, drag-and-drop, menus or animations; those were tested by hand only.
